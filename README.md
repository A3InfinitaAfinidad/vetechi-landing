# VETECHI - Hospital Veterinario 24/7

Hospital Veterinario premium en David, Chiriquí — únicos con atención 24/7 los 365 días del año.

## Installation

```bash
npm install
npm run build
npm run preview
```

## Deployment

```bash
npm run build
# El output va a ./out — subir a Cloudflare Pages
```

## i18n

- `/es` — Español
- `/en` — English

## SEO

- Metadatos completos en `app/[locale]/layout.tsx`
- Schema.org JSON-LD (VeterinaryCare + LocalBusiness + Person)
- Sitemap en `/sitemap.xml`
- Robots.txt configurado
